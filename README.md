# 📝 ToDo List em React

Este é um projeto de **lista de tarefas (ToDo List)** desenvolvido utilizando **React puro**, com foco em simplicidade, usabilidade e organização.
A aplicação permite **criar, editar, excluir e marcar tarefas como concluídas**, mantendo os dados salvos diretamente no navegador através do **localStorage**.

🔗 **Acesse a aplicação:**
👉 [https://igorsb3000.github.io/todolist-react/](https://igorsb3000.github.io/todolist-react/)

---

## 🚀 Funcionalidades

- ➕ **Adicionar tarefa**
- 🖊️ **Editar tarefa existente**
- 🗑️ **Excluir tarefa**
- ✔️ **Marcar tarefa como concluída (checkbox)**
- 💾 **Salvar automaticamente no localStorage**
- 📱 **Layout totalmente responsivo**
- ✂️ **Ajuste automático para textos grandes**
- ⚠️ **Modal de confirmação para exclusão**

## 📦 Como executar o projeto localmente

```bash
# Clone o repositório
git clone https://github.com/igorsb3000/todolist-react.git

# Acesse a pasta do projeto
cd todolist-react

# Instale as dependências
npm install

# Execute o projeto
npm run dev
```

A aplicação será iniciada em:
**[http://localhost:3000](http://localhost:3000)**
